Migration checklist

ทำตามลำดับก่อนเปลี่ยนคอม รายการที่ติ๊กเสร็จจะจำไว้ใน Browser เครื่องนี้เท่านั้น

บันทึกชื่อ หมวด Tier แหล่งที่มา และ Notes เป็น JSON เพื่อนำเข้าเว็บนี้ในคอมใหม่

ดาวน์โหลด PowerShell จากเว็บนี้ แล้วรันในเครื่องเก่า สคริปต์จะค้นหา `SKILL.md` ตามโฟลเดอร์ CLI ที่พบบ่อย และสร้าง ZIP กับรายงาน JSON (ไม่สำรอง Config/API Keys)

powershell -NoProfile -ExecutionPolicy Bypass -File ".\skill-vault-backup.ps1"

ตรวจอ่านสคริปต์และ ZIP ก่อนใช้หรือส่งต่อ โดยเฉพาะหากมีไฟล์ส่วนตัวในโฟลเดอร์ Skill

นำไฟล์ `skill-vault-scan.json` ที่สคริปต์สร้างเข้ามาเพื่อจับคู่ชื่อกับ Path ที่พบจริง แล้วตรวจว่า Skills สำคัญครบหรือไม่

ยังไม่ได้ Import รายงานจากเครื่อง

เก็บ HTML + JSON + ZIP ไว้บนไดรฟ์ที่ย้ายได้ ติดตั้ง CLI/Plugins บนคอมใหม่ให้เรียบร้อย จากนั้น Restore Skill ไปยัง Path ที่ถูกต้อง และ Import JSON กลับเข้าเว็บ
